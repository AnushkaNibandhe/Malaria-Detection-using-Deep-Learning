Project context & guidance

This tool screens microscopic thin blood smear images for malaria parasites using deep learning models trained on the NIH cell image dataset (Giemsa-stained, PNG format).

Pipeline
  • Upload single-cell RGB image of a blood smear.
  • Images are normalized and resized for the best-performing CNN.
  • Model outputs infection status plus confidence estimates.
Binary classes: Parasitized / Uninfected Input: single RBC patch

Three architectures were trained for comparison on a balanced subset of the NIH dataset, with the custom CNN selected as the deployment model.

Target metrics (validation)
  • Custom CNN: accuracy ≥ 98.99%, ROC-AUC ≥ 0.9995 (best model).
  • MobileNetV2: accuracy ≈ 81.31%, ROC-AUC ≈ 0.89.
  • EfficientNetB0: accuracy ≈ 50%, ROC-AUC ≈ 0.50 (baseline).
Model stack
  • Custom CNN optimized for 64×64 RBC crops.
  • Transfer learning with MobileNetV2 and EfficientNetB0.
  • Best checkpoint exported as malaria_detector_final.h5.

This interface is intended for rapid triage and educational demonstration, not as a stand-alone diagnostic system.

How to use
  • Prefer cropped, focused single-cell patches from thin smears.
  • Avoid over/under-exposed images or heavy compression artifacts.
  • Use the reported confidence and processing time for quality control.
Clinical caveats
  • Predictions must always be reviewed by a qualified pathologist.
  • Model is trained on a specific staining protocol (Giemsa) and may not generalize to all labs.
  • Best suited for screening and decision support in resource-limited settings.
